This project focuses on detecting diseases in potato plant leaves using a Convolutional Neural Network (CNN) model trained on the PlantVillage dataset. It classifies potato leaf images into three categories: Early Blight, Late Blight, and Healthy. The solution aims to support farmers and agricultural applications through automated and accurate crop disease diagnosis, reducing crop loss and improving yield outcomes. The model is implemented using TensorFlow/Keras, includes preprocessing and augmentation techniques, and achieves strong accuracy on the test dataset.
